# BUMP

BUMP is an Android lyric visualizer focused on cinematic typography motion.

## V0.1
- Full-screen monochrome visualizer
- Word-by-word lyric timeline
- Perspective/depth movement
- Faux 3D extrusion
- Motion glow/trails
- Tap to play/pause
- GitHub Actions cloud APK build

## Roadmap
1. Real local audio playback synchronized to lyrics
2. LRC import and word timing editor
3. Ship-style 3D word wall
4. Fisheye lens shader
5. More visual modes
6. Spotify/Apple Music integrations using their supported APIs and policies
7. Export/render pipeline
